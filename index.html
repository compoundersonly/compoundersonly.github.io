Shorts Poster

A personal publishing tool for one creator's own short videos.

What it does

Shorts Poster runs on its owner's computer. When the owner finishes a short educational video about companies and investing, the tool writes a title and caption for it and uploads it, at a scheduled time, to the owner's own accounts:

  • YouTube Shorts, through YouTube API Services (YouTube Data API v3)
  • Instagram Reels, through Meta's Instagram Graph API
  • TikTok, through TikTok's Login Kit and Content Posting API
  • X, through the X API (OAuth 2.0, media upload and posts)

It signs in with each platform's official sign-in page, posts only videos the owner made, and only to accounts the owner controls.

Who can use it

Only its owner. It isn't a public service or app store product, and there are no other users or accounts.
